# RimWorld Diagnostics Toolkit (RWDT)

The RimWorld Diagnostics Toolkit (RWDT) is a developer-focused runtime observability and diagnostics toolkit being developed by ThelianTech for RimWorld.

The project is intended to support runtime monitoring, troubleshooting, performance analysis, debugging, and the validation of game and mod behavior.

## Target Environment

- RimWorld 1.7
- Waylith Engine
- .NET 10

## Development Status

This project is currently in its conceptual planning and early development stages.

This repository will serve as the central location for the toolkit's source code, development documentation, and supporting software components.

Additional information regarding the project's architecture, functionality, installation, usage, and development will be provided as the project progresses.
